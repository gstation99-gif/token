# Supercell ID HDX Token Servisi (GitHub & Render Uyumlu)

Bu uygulama, telefonunuzdan veya engelsiz bir ağ üzerinden Supercell ID'ye giriş yaptığınızda elde ettiğiniz oturum verilerini (JWT, çerez, ham JSON) doğrudan **[PlayerID] [PassToken] [JWT]** HDX bot formatına dönüştüren bulut tabanlı bir web servisidir.

## Render Üzerinde Yayınlama:
1. Bu klasördeki dosyaları bir GitHub deposuna yükleyin.
2. Render Dashboard'a girip **New > Web Service** seçeneği ile deponuzu bağlayın.
3. **Runtime** olarak **Docker** seçip servisi başlatın. Sizin için özel bir bulut linki oluşacaktır.
